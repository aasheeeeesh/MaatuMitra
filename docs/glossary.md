# Glossary

Plain definitions of every technical word used in this project. Builders add terms through
`<module>/handoff/glossary.md` (format `- **Term**: definition`); terms already here are skipped.

- **AMR (antimicrobial resistance)**: when bacteria stop responding to antibiotics, often because antibiotics are overused or misused.
- **ASR (automatic speech recognition)**: software that turns speech audio into written text.
- **ASHA worker**: an Accredited Social Health Activist, a community health worker in India who visits households.
- **AWaRe**: the WHO grouping of antibiotics into Access, Watch and Reserve, by how carefully they should be used.
- **Bootstrap**: estimating uncertainty by re-sampling the data many times with replacement and recomputing the metric each time.
- **CER (character error rate)**: how many characters must be inserted, deleted or changed to turn the computer's text into the correct text, divided by the length of the correct text.
- **CI (confidence interval)**: a range that likely contains the true value; we use 95% intervals.
- **Code point**: one Unicode character number (for example U+0C95 is ಕ). Our text offsets count code points.
- **Code-switching**: mixing two languages in one sentence, for example English drug names inside Kannada speech.
- **Contract**: an agreed data format (here a JSON Schema plus a few extra rules) that two modules use to talk to each other.
- **Evidence (span)**: the exact piece of the transcript (start and end position plus the words) that supports one item in a record.
- **Extras (optional extras)**: groups of extra Python packages that are installed only when asked for, for example `uv sync --extra asr`.
- **Fail-closed**: when something goes wrong or is unclear, the system stops and asks a human instead of letting things through.
- **Fixture**: a small hand-made example file used for testing before real data exists.
- **Git Bash**: the bash command shell that comes with Git for Windows; our Makefile needs it on Windows.
- **Gold (gold standard)**: the known correct answer, used to score the system.
- **Grapheme cluster**: what a reader sees as one letter, which in Kannada can be several code points (a consonant plus vowel sign, for example ಕಿ).
- **Hook (Claude Code)**: a command that Claude Code runs automatically before or after a tool is used; it can block actions.
- **JSON Schema**: a standard way to describe what a JSON file must contain; "draft 2020-12" is the version we use.
- **Lexicon**: a word list with extra information; here, drug names with spellings, classes and dose ranges.
- **Lockfile**: a file listing the exact version of every package, so everyone installs the same thing (here `uv.lock`).
- **MAX_PATH**: the old Windows limit of 260 characters for a file path.
- **NFC (Unicode Normalization Form C)**: a standard way to store Unicode text so the same letters always have the same code points.
- **Pre-registration**: writing down hypotheses and pass/fail thresholds before running the experiment, so results cannot shape the rules.
- **RLS (row-level security)**: a PostgreSQL feature that decides, row by row, which rows a database user may see or change.
- **Rule of three**: if something failed 0 times in N tries, the 95% upper bound of its failure rate is about 3/N.
- **Secret scanning (gitleaks)**: a tool that searches code and git history for passwords or keys that should not be there.
- **Skill (Claude Code)**: a folder with a SKILL.md file that gives an agent extra instructions for a type of task.
- **Subagent (Claude Code)**: a separate AI helper with its own instructions and tool permissions, defined in `.claude/agents/<name>.md`.
- **Test split**: the part of the data kept aside and used only once, at the end, to measure the final result honestly.
- **TTS (text-to-speech)**: software that turns written text into spoken audio.
- **uv**: a fast Python package and environment manager that writes a lockfile.
- **UUID**: a long random identifier (like 1b4e28ba-2fa1-11d2-883f-0016d3cca427) that cannot be guessed, unlike 1, 2, 3.
- **venv (virtual environment)**: a private folder of Python packages for one project.
- **WER (word error rate)**: like CER but counted in whole words.
- **Wilson interval**: a good way to compute a confidence interval for a proportion (k successes out of n), even when k is 0 or n is small.
- **ruff**: a fast tool that checks Python code style and common bugs, and formats code.
- **FORCE ROW LEVEL SECURITY**: makes RLS apply even to the table's owner (without it, owners skip the rules).
- **Policy**: one RLS rule, e.g. "a nurse may SELECT patients whose facility is her facility".
- **GUC (Grand Unified Configuration setting)**: a named setting inside a PostgreSQL session, like `app.user_id`; our policies read them to know who is asking.
- **SET LOCAL**: changes a setting or role only until the end of the current transaction, so it cannot leak to the next request on the same connection.
- **Connection pool**: a set of open database connections reused by many requests.
- **NOINHERIT**: a role option meaning "do not automatically get the rights of roles you are a member of"; you must switch with SET ROLE.
- **BYPASSRLS / superuser**: role powers that ignore RLS completely; none of our request roles have them.
- **security_barrier view**: a view PostgreSQL treats as a security boundary, so tricky user functions cannot peek at rows the view filters out.
- **SECURITY DEFINER function**: a function that runs with its owner's rights instead of the caller's; used here only for writing audit rows.
- **Append-only**: data can be added but never changed or deleted.
- **HMAC-SHA256**: a keyed hash: the same input and key always give the same output, but without the key you cannot compute or reverse it.
- **Pseudonym**: a stand-in identifier (here a truncated HMAC of the patient id) that lets researchers link a patient's rows without knowing who it is.
- **JWT (JSON Web Token)**: a signed text token that says who the user is and which role they have.
- **alg none attack**: sending a JWT that claims "no signature needed"; a correct server must refuse it.
- **Mass assignment**: a client sneaking extra fields (like `role`) into a request body hoping the server saves them.
- **IDOR (insecure direct object reference)**: getting someone else's data by changing an id in the URL.
- **SQL injection (SQLi)**: smuggling SQL commands inside text input; prevented by parameterised queries.
- **Access matrix (E5)**: the automated table of roles x resources x actions x ownership (+ attacks) with the expected allow/deny for each.
- **Verdict**: the verifier's output for one record: a list of checks with pass / flag / n/a and a reason.
- **auto_acceptable**: true only when no check flags and at least one check passed; otherwise a human must review.
- **Rule registry**: a table that maps each check id (C1..C8) to its function, so one check can be switched off by config.
- **Ablation**: switching off one part of a system to measure how much that part contributes (experiment E3).
- **Clause**: a piece of a sentence with its own verb or meaning; here it is cut at punctuation and at words like ಆದರೆ (but) and ಮತ್ತು (and).
- **Negation cue**: a word or word ending that means "not", for example ಇಲ್ಲ or the ending -ಿಲ್ಲ.
- **Minimal-pair twin**: the same sentence with only the negation removed or changed, used to test that a rule fires for the right reason.
- **Trap token**: a word that looks like a negation but is not one, for example ಇಲ್ಲಿ (here) or ಮಾತ್ರೆ (tablet).
- **Soft cue**: a word that may be a negation but is uncertain (for example casual -ಲ್ಲ on an unknown verb); it is counted as negation and also flagged for review.
- **Cross-turn negation**: a "no" in one speaker turn (a bare ಇಲ್ಲ) that answers a question asked in the previous turn.
- **Encounter index**: a list saying which audio/transcript belongs to which patient; needed to check the patient link.
- **Planted mistake**: an error we insert on purpose to see whether the verifier catches it (experiment E4).
- **Unique mutation**: one distinct planted change; repeating the same change many times does not add independent evidence.
- **Review burden**: the share of error-free fields that the verifier still flags, i.e. extra work for the human reviewer.
- **Template**: a sentence pattern with blanks (slots) that the generator fills to make many synthetic conversations.
- **Template family**: a group of templates that share sentence frames; a whole family goes to either dev or test, never both.
- **Slot**: a typed blank in a template (drug, symptom, count, word, negation, cross-turn answer).
- **Drug-dose combination**: a drug together with a spoken dose, e.g. (amoxicillin, 500, mg); each one is used in only one split.
- **Test lock**: a file listing a fingerprint (sha256) of every test file; if any test file changes, the check fails.
- **sha256**: a fingerprint of a file's bytes; changing one byte changes it completely.
- **Deterministic generator**: a program that produces exactly the same files every time it runs with the same inputs and seed.
- **Seed**: a fixed number that makes "random" choices repeatable.
- **Transliteration**: writing a word in another script by sound (amoxicillin -> ಅಮಾಕ್ಸಿಸಿಲಿನ್), not translating it.
- **ISO 15919**: a standard way to write Indian-script sounds with Latin letters (ā, ṭ, ḍ, ṁ ...).
- **WHO AWaRe**: WHO's grouping of antibiotics into Access, Watch and Reserve by resistance risk.
- **NLEM**: India's National List of Essential Medicines (2022 edition used here).
- **openFDA drug label**: the US FDA's official prescribing text for a medicine, available as public data.
- **Attested word**: a word we actually saw in a fetched real Kannada text; unattested words were composed by an AI.
- **AppTest**: Streamlit's built-in test tool (`streamlit.testing.v1.AppTest`). It runs the app script without a browser and lets a test click buttons and read what is shown.
- **XSS (cross-site scripting)**: an attack where text such as `<script>` inside data is treated by the browser as code. Prevented by escaping the text first.
- **Escaping (HTML)**: replacing characters like `<`, `>`, `&` and quotes with safe codes (`&lt;` ...) so the browser shows them as text instead of running them.
- **WCAG AA contrast**: an accessibility rule: normal text needs a brightness contrast ratio of at least 4.5 to 1 with its background; icons and borders at least 3 to 1.
- **Touch target**: the area of a button that a finger can tap; we use at least 48 x 48 pixels.
- **Conjunct (ottakshara)**: a group of Kannada consonants joined by a virama (ಕ + ್ + ಷ = ಕ್ಷ) and drawn as one combined shape.
- **Variable font**: one font file that contains every weight (thin to black) instead of one file per weight.
- **SIL Open Font License (OFL) 1.1**: a free licence for fonts that allows using and bundling the font with software; the font may not be sold on its own.
- **Save gate**: the server-side rule that refuses to save a record unless it was approved and its verifier result has no open flags.
- **Stand-in (mock verifier)**: a small fake used in mock mode so the UI can be tested without the real verifier; it is not the real safety logic.
- **Repha (arkavattu)**: the special raised form of ರ when it comes first in a Kannada conjunct (ರ್ಕ).
- **Rules pipeline**: a program made of hand-written rules (word lists and patterns) that turns a transcript into a record. Same input always gives the same output.
- **Evidence span**: the exact piece of the transcript (start and end character positions) that supports one value in the record, for example "ಅಮಾಕ್ಸಿಸಿಲಿನ್ 500 mg".
- **Evidence check**: a test that cuts the transcript at the stated positions and confirms the piece equals the quoted text. If any quote in a record fails, the whole record is rejected.
- **Forged span**: a deliberately wrong quote or position, used in a test to prove the evidence check catches it.
- **Edit distance (Levenshtein)**: the smallest number of single-letter insertions, deletions or substitutions that turn one word into another ("azithromycn" to "azithromycin" is 1).
- **Comparison form**: a copy of a word used only for matching: invisible joiners removed, Kannada digits turned into 0-9, lower case. The stored text is never changed.
- **Cross-turn answer**: a turn that is only "ಇಲ್ಲ" (no) or "ಹೌದು" (yes); it answers the question in the previous turn.
- **Coordination rule**: in "ನೆಗಡಿ ಮತ್ತು ಕೆಮ್ಮು ... ಇದೆ" (cold and cough ... are present) a bare noun before "and" shares the verb of the next part.
- **dev_tune / dev_holdout**: two parts of the DEV split made by m3. dev_tune conversations were read while writing rules; dev_holdout templates (a3 b4 c5 d2 e6 f3 g5 h6 i3) were not, so their score estimates how rules do on unseen wording.
- **In-sample score**: a score measured on the same examples used to build the system. It is optimistic and says little about new data.
- **JSON-schema-constrained output**: the LLM server only lets the model produce text that fits a given JSON structure (field names, allowed values).
- **Ollama digest**: the sha256 fingerprint of a model file in Ollama; it pins the exact model version.
- **Errors per 1,000 fields**: number of wrong fields divided by number of fields checked, times 1,000.
- **MA-WORDING-UNJUDGED**: our code for advice or follow-up text that differs from the gold English gloss; a computer cannot judge "same meaning", so it is counted as MAJOR (severity rule 5).
- **Verdict (stored)**: the verifier's result for one record, saved by the server in the `verdicts` table so a client cannot supply its own.
- **Resolution**: a physician's answer to one flag when saving: "confirmed" (looked, it is correct) or "edited" (fixed the field and re-verified).
- **Record hash**: a fingerprint of a record's content computed by the database; a verdict is only valid for the exact content it was computed for.
- **Stale verdict**: a verdict whose record was changed afterwards, so it no longer describes the saved content.
- **DISCARD ALL**: a PostgreSQL command that forgets everything session-level (role, settings, temp objects, prepared statements); the pool runs it on every returned connection.
- **Small-cell suppression (k-anonymity)**: dropping groups with fewer than k people from a dataset so no one stands out; here k = 5.
- **Pseudonym map**: a private table linking a patient id to the research pseudonym, used only to delete research rows when consent is withdrawn.
- **Trigger**: a database rule that runs automatically when rows change; ours block unapproved saves, protect append-only tables and remove research rows on consent withdrawal.
- **REFREEZE-1**: the one planned regeneration and relock of the frozen test split, done before any test evaluation.
- **Syrup (child_syrup slot)**: a paediatric liquid dose given in ml; the generator's `child_syrup` dose kind produces only ml, `given` produces only adult mg/tablet doses.
- **generate: false**: a negation-table entry that readers must match but the data generator is not required to produce.
- **Allow-list**: a list of the things that ARE allowed (here: the dev conversation ids in data/splits/dev.txt); anything not on it is refused. Safer than a deny-list, which only refuses what it already knows about.
- **Field-level attribution**: counting a planted error as "caught" only when a flag points at the exact field that was changed (or its item), not when some unrelated flag anywhere in the record happens to fire.
- **Detected (E4)**: a stricter "caught": the flag on the changed field is a real-violation flag (not "cannot verify") and it was not already there on the error-free version of the same record.
- **cannot_verify**: a verifier reason code meaning "the rules cannot check this value" (for example a child's dose, or a drug with no dose range in our list). It sends the item to a human but is NOT evidence that the value is wrong.
- **Oracle second transcript**: a second transcript that is known to be correct (here: the uncorrupted gold text). Results that use it are an upper bound: a real second speech-recognition output has its own mistakes.
- **Upper bound**: the best a method could possibly do under ideal conditions; real results will be the same or worse.
- **Confusable drug**: a drug whose name looks or sounds like another one (for example ciprofloxacin and levofloxacin), so it could be swapped by mistake.
- **Reason code**: a short machine-readable label at the start of a verifier flag (for example `out_of_range [CR-DOSE]:`), so reports can count kinds of flags.
- **Finite predicate**: the verb that ends a Kannada clause (for example ಇದೆ "is there", ಇಲ್ಲ "is not"). A new clause can start right after it even without a comma.
- **Negative question**: a question asked in the negative ("won't you drink?", ಕುಡಿಯಲ್ವಾ?). A yes/no answer to it is hard to read, so the verifier flags it.
- **Fused symptom word**: a Kannada noun and its ending written as one word, for example ಜ್ವರವಿಲ್ಲ = ಜ್ವರ (fever) + ಇಲ್ಲ (not). m3 builds these forms with a grammar rule no native speaker has checked.
- **STALE result**: a saved result made on data or code that has since changed; kept for history, not scored or quoted as current.
- **Additive versioning**: adding a new version of a format (record.v2) next to the old one (record.v1) instead of changing the old one, so programs that use the old one keep working.
- **Route of administration**: how a medicine enters the body: by mouth (oral), into a vein (IV), into a muscle (IM), under the skin (SC), on the skin (topical), breathed in (inhaled), rectal.
- **Strength (of a medicine)**: how much drug is in one unit of the product, for example 500 mg per tablet or 120 mg per 5 ml of syrup. Different from the dose, which is how much is given each time (1 tablet, 5 ml).
- **Formulation**: the physical form of a medicine: tablet, capsule, syrup, suspension, drops, injection, sachet.
- **As needed (PRN)**: a medicine given only when a symptom is present ("only if there is fever"), not on a fixed schedule.
- **Medication status**: in record.v2, what the record claims about a drug: prescribed now, already taken, not taken, advised against, stopped early, continue an existing drug, or unknown.
- **Field evidence**: in record.v2, a separate evidence span (the exact words in the transcript) for each new field that is filled in, such as the word "injection" for the route.
- **Bidi control character**: an invisible Unicode character (U+202A..U+202E, U+2066..U+2069) that changes the direction in which text is displayed; it can make shown text differ from stored text.
- **Migration (of data)**: converting documents from an old format version to a new one with a program (here contracts/migrate_v1_to_v2.py).
- **Age band**: a coarse age group (infant, child, adolescent, adult, older adult) used instead of an exact age.
- **Gated model**: a Hugging Face repository that only lets you download after you log in and accept its terms; without an access token the download fails with HTTP 401.
- **MMS-TTS**: Meta's "Massively Multilingual Speech" text-to-speech models; the Kannada one (mms-tts-kan) has a single voice.
- **Held-out voice**: a synthetic voice used only for the test split, so a model tuned on dev never heard it.
- **Pitch shift**: changing how high a voice sounds without changing how long it lasts; here it makes a lower-sounding copy of the same synthetic speaker (not a new speaker).
- **SNR (signal-to-noise ratio)**: how much louder the speech is than the added noise, in dB; 20 dB is mild noise, 5 dB is very noisy.
- **White noise / pink noise**: random hiss with equal energy at all pitches (white) or more energy in low pitches (pink, like rain or a crowd).
- **Pagefile**: a hidden Windows file (here about 25 GB) used as spare memory; it grows when RAM is short and only shrinks after a restart, so it can silently eat free disk space.
- **Streaming extraction**: reading a big archive over the network while it downloads and keeping only the few files you need, so the archive never sits on disk.
- **Abstain**: the helper refuses to answer and says "not sure, ask a doctor".
- **Safety gate**: hand-written rules that block dose, pregnancy, diagnosis, child-drug and similar questions before any card is looked up.
- **TF-IDF**: a word-counting score that gives rare words more weight; cosine similarity then compares two such count vectors.
- **Embedding**: a list of numbers standing for the meaning of a text, so similar texts get similar lists.
- **Demo mode**: helper mode that shows unreviewed draft cards with a visible DRAFT label.
- **Held-out (test) split**: questions never used to choose the threshold.
- **Cluster bootstrap**: estimating uncertainty by resampling whole groups (here: template families) instead of single items, because items in one group tend to fail together.
- **Paired bootstrap**: comparing two systems on the SAME items by resampling the per-item differences; a difference counts only if its 95% range excludes zero.
- **Seen frame / unseen frame**: whether a test sentence pattern (with names and numbers blanked out) also occurs in a dev template.
- **Automation bias**: trusting a machine's warnings so much that people miss problems the machine does not point at.
- **Within-subject design**: every participant does every condition (here: flags shown and flags hidden), so people are compared with themselves.
- **SUS (System Usability Scale)**: a 10-question usability questionnaire scored 0 to 100.
- **Grapheme CER**: character error rate counted on visible letter clusters (a Kannada letter with its signs counts once).
- **Real-time factor (RTF)**: processing time divided by audio length; below 1 means faster than real time.
- **In-sample**: measured on the same data that was used to build or fix the system, so it overestimates performance on new data.
