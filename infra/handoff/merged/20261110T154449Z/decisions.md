### D-?: Kannada review of m4, m1 and m3: gaps in the negation rules and wording fixes for REFREEZE-1   (Phase B / m4_verify, m1_data, m3_extract / orchestrator / 2026-11-10)
- What we needed to decide: The simulated Kannada reviewer (reviews/{m4_verify,m1_data,m3_extract}/2026-11-10-kannada.md, label ai_simulated_review, run on the cheaper Sonnet model per D-65) found missing negation forms, a clause-splitting bug and several unnatural sentences. Which findings do we accept, and where are they fixed?
- Options we considered: (1) Accept everything and fix it in the coming fix passes. Pro: one round of fixes. Con: some suggestions rest only on the model's own knowledge (low confidence). (2) Accept only findings backed by a fetched source. Pro: strict. Con: only ONE source page was fetched (en.wiktionary pages returned 404), so almost everything would be ignored, including clear bugs. (3) Accept findings that are either source-backed OR testable bugs (a sentence our own data or a plain example shows is mishandled), mark the rest "low confidence", and send all of them to the human Kannada sheets.
- What we chose: Option 3. All "major" findings are accepted because each one is a concrete, testable case.
- Why: A rule that misses ತಗೋಬೇಡಿ ("don't take") or marks fever as absent in "ಜ್ವರ ಇದೆ ಕೆಮ್ಮು ಇಲ್ಲ" ("fever yes, cough no") is a safety bug whether or not a web page says so. But we must not pretend these fixes are native-validated.
- What we actually did: Validated all three reports against review_report.v1 (all valid; the reviewer had no shell). Assigned the fixes. m4 fix pass (Opus): ಬೇಡ/ಬೇಡಿ attached directly to a verb (ತಗೋಬೇಡಿ, ಕೊಡ್ಬೇಡಿ); missing whole-word cues ಬೇಡಾ, ಬೇಡವಾ, ಇಲ್ರೀ, ಇಲ್ಲಪ್ಪ; the colloquial negative question -ಲ್ವಾ (backed by a fetched grammar page); split clauses when a second "subject + ಇದೆ/ಇಲ್ಲ" starts without punctuation; cross-turn answers of more than one word ("ಇಲ್ಲ ಅಕ್ಕ", "ಹೌದ್ರೀ"). Shared table .claude/skills/kannada-nlp/negation_table.yaml (orchestrator/architect, before the m3 fix pass): stop matching ಬೆಲ್ಲ (jaggery), add the negative-question cue and ಆಗದೆ, do not split clauses at the dots inside abbreviations like ಎಂ.ಜಿ. m1 REFREEZE-1 (Sonnet): use the reviewer's child-syrup wording for a3, e8, h2, h3, i5 and "ಎರಡೂ ಔಷಧಿ ಒಟ್ಟಿಗೆ ಕೊಡಬಹುದಾ?" for e2; replace "ಕೊಡುವುದು ಬೇಡಿ" with "ಕೊಡಬೇಡಿ" in _forms.yaml; fix the nonsense positive twins of h5, e7 and h2; spell ORS with ಓ in the annotation guide; consider generating ಸಲ. m3 fix pass (Sonnet): accept ಆಗಿದ್ದರೆ in the fever-follow-up pattern, fused symptom negation like ಜ್ವರವಿಲ್ಲ, and ಪ್ಯಾಕೆಟ್ as a sachet unit.
- What could go wrong / weaknesses: Only one external source was fetched, so most findings are "model knowledge only, low confidence". The 30% template sample did not use the requested seed; the reviewer used a reproducible every-third-template rule instead (20 templates plus 4 extra), listed in the m1 JSON. The m1 .md contains one garbled phrase about the sampling method (the JSON is correct). Adding new negation cues may raise false flags; the trap tests must stay at zero false triggers.
